# Data Directory

Large data files should not be committed to git. Place or symlink files here
before running the workflow.

```text
data/raw/
  gwas_catalog_v1.0.2-associations_e115_r2026-04-27_full.tsv
  variant_summary.txt.gz

data/interim/gnomad_v4_AF/
  gnomad_v4_AF_chr1.txt.gz
  ...
  gnomad_v4_AF_chrY.txt.gz

data/processed/
  clinvar_gnomad_v4_joined_allele.tsv
  gwas_catalog_gnomad_v4_joined.tsv
```

The `data/processed` files are generated by:

```bash
python scripts/prep_gnomad_clinvar_join.py
```
